# genomic-prs-demo

DFU·PAD·CKD **다유전자 위험점수(PRS) 자동화 파이프라인** — 연구자 입력형 인터랙티브 데모.

디지털 헬스케어 학회 포스터의 QR이 가리키는 공개 데모 페이지입니다. 단일 HTML 파일(`index.html`)로, 브라우저에서 질환을 1~5개 선택하면 PRS 분포·6조합 상관·위험계층을 즉시 산출합니다.

🔗 **Live:** https://healthcare-pro.github.io/genomic-prs-demo/

> ⚠️ 대시보드의 다질환 상관 수치는 잠재 위험축 기반 **근사값(브라우저 시연용)** 입니다. 실측 검증값은 DFU~CKD r=0.187 (1000 Genomes chr22, 개념검증)이며, 전체 파이프라인 코드는 별도 비공개 저장소에서 관리합니다.
